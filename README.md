Kaduna North Waste Management Analytics

Project Overview

This project demonstrates Python-based descriptive data analysis and visualization using aggregated survey results from my Master’s research on population density and waste management systems in Kaduna North Local Government Area, Nigeria.

The original research involved 400 respondents and examined waste generation, collection efficiency, environmental infrastructure, and community participation.

Key Research Findings

* 81% perceived population density as high or very high.
* 77% rated waste collection services as ineffective or very ineffective.
* 70% considered waste management infrastructure inadequate or very poor.
* 76% were unaware of existing waste management policies.
* 77% expressed willingness to participate in community waste management initiatives.

Analytical Tools

* Python
* Pandas for data analysis
* Matplotlib for data visualization
* Jupyter Notebook for reproducible analysis

Research Interests

Geospatial Analytics, Geographic Information Systems (GIS), Environmental Data Science, Remote Sensing, and GeoAI.

Data and Methodology

The computational project reproduces descriptive statistics and visualizations from published summary tables in the Master’s research. It does not use individual respondent records or claim to have performed spatial modelling or machine learning.

Project Transparency

The Python implementation was developed as a subsequent portfolio exercise with AI assistance. It is distinct from the original Master’s research methodology.
